*wordmotion.txt* More useful word motions for Neovim

INTRODUCTION				    *wordmotion*

A Lua rewrite of vim-wordmotion for Neovim. Vim treats
`CamelCaseACRONYMWords_underscore1234` as one word. This plugin
splits it into six words: >
	CamelCaseACRONYMWords_underscore1234
	^    ^   ^      ^     ^         ^
<
WORDS					    *wordmotion-words*

A `word` is any of the following:
- An uppercase letter followed by one or more lowercase letters
- One or more uppercase letters that does not immediately precede
  a lowercase letter
- One or more lowercase letters
- A valid hex color code
- A valid hex literal
- A valid octal literal
- A valid binary literal
- One or more numeric digits
- One or more of other printable characters
- An empty line

Default space characters (where `w` stops):
1. Whitespace
2. Hyphens (`-`) between alphabetic characters
3. Underscores (`_`) between alphanumeric characters

MAPPINGS					    *wordmotion-mappings*

Default mappings: >
	<M-w>    [count] words forward (exclusive)
	<M-e>    forward to the end of word [count] (inclusive)
	<M-b>    [count] words backward (exclusive)
	g<M-e>   backward to the end of word [count] (inclusive)
	a<M-w>   "a word" text object
	i<M-w>   "inner word" text object (aw behaves identically)

All mappings work in normal, visual, and operator-pending modes
(aw/iw only in visual and operator-pending).

CUSTOMIZATION				    *wordmotion-customization*

Configure via `setup()`: >
	require("wordmotion").setup({
	  mappings = {
	    ["w"] = "<Leader>w",
	    ["e"] = "<Leader>e",
	    ["b"] = "<Leader>b",
	    ["ge"] = "<Leader>ge",
	    ["aw"] = "a<Leader>w",
	    ["iw"] = "i<Leader>w",
	  },
	})

Unspecified entries use the defaults. Set to "" to disable a mapping.
